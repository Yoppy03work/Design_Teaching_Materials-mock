# 動画ソース（NotebookLM 用）

`video_scripts.md` を動画ごとに分割したもの。NotebookLM の **Video Overview（動画解説）** にそのまま読み込ませる用。

| ファイル | 動画 | 目安 | 使う STEP | video_id |
|---|---|---|---|---|
| `01_intro.md` | 教師イントロ | 3分 | STEP1 | `intro` |
| `02_grandfather.md` | 祖父紹介 | 5分 | STEP1 | `grandfather_intro` |
| `03_vision.md` | 動画①「祖父の見え方を知ろう」 | 5分 | STEP2 | `video1` |
| `04_wcag.md` | 動画②「WCAGとデザインの原則」 | 5分 | STEP4 | `video2` |
| `05_summary.md` | 動画③「まとめ＋次時予告」 | 2分 | STEP7 | `video3` |

## 作り方（NotebookLM）
1. [notebooklm.google.com](https://notebooklm.google.com) で新しいノートブックを作成
2. **ソースに、その動画のファイル1つだけ**を追加（内容がブレないよう1本＝1ノートブック推奨）
3. **Studio → Video Overview（動画解説）** を選ぶ
4. カスタマイズ：**言語＝日本語** / **形式＝Explainer** / **ビジュアル＝Classic か Whiteboard**（祖父紹介だけ Watercolor/Heritage も可）/ 下のステアリングプロンプトを貼り、**「約N分」も明記**
5. **Generate** → ダウンロード → YouTube に限定公開でアップ → `lib/videos.ts` の該当 `youtubeId` を差し替え

> 注意：NotebookLM はAIが要約・再構成して**自分のナレーション・自分の絵**で作ります（台本の逐語読みではない）。逐語・自分の声がよければ TTS か自分で録音を。ペルソナ「祖父」は架空。他社サイトのスクショは使わない。

## ステアリングプロンプト

**① intro（約3分）**
> 高校1年生向けの導入動画。情報I「アクセシブルなデザイン」。約3分・やさしい語り口。順に：(1)テーマ「アクセシブル＝誰もがたどり着ける」、(2)本時の流れ（動画→配色エディタで設計→作品ライブラリ→振り返り、自分のペースでOK）、(3)基発問「スマホやWebで“見にくい・使いにくい”と感じた経験は？」を投げかけて考えさせる、(4)「次は祖父を紹介します」で締める。専門用語は避け、断定しすぎない。

**② grandfather（約5分）**
> 高校1年生向け、約5分。今日デザインする相手＝架空のペルソナ「祖父（68歳）」を“人物として”紹介し「この人のためにデザインしたい」という動機を引き出す。盛り込む：元小学校の先生／退職後は庭で植物を育てる／穏やかで好奇心がある／一番の楽しみは離れて暮らす孫（＝あなた）の写真を見ること／スマホはあるが操作はゆっくりで小さいボタンを押し間違える等の“少しの不便”。温かい語り口。見え方の詳しい話は次の動画に回し、人柄と文脈に集中。架空の人物で実在の家族情報は扱わない。

**③ vision（約5分）**
> 高校1年生向け、約5分。祖父の見え方＝色覚多様性（赤と緑が見分けにくい赤緑色弱）と老眼を、当事者に配慮してやさしく解説。盛り込む：人によって色の見え方が違う（P型/D型/T型の3タイプ）、特にD型で赤と緑が似て見える、老眼で小さい文字や低コントラストが読みにくい、これは本人のせいではなくデザインで補えること。次の「シミュレータ体験」につながる締め。

**④ wcag（約5分）**
> 高校1年生向け、約5分。WCAGのコントラスト比とアクセシブルな配色の原則を解説。盛り込む：コントラスト比＝背景と文字の明暗差、目安 AA(4.5:1)/AAA(7:1)/大きい文字AA(3:1)、色だけで情報を区別しない、文字を大きく。最後に主発問「基準の数字を満たしても、必ずしもその人に届くとは限らない。本当に祖父に届くデザインとは？」を投げかけ、配色設計の演習につなげる。

**⑤ summary（約2分）**
> 高校1年生向け、約2分。本時の振り返りと次時予告。盛り込む：今日の流れ（相手を知る→見え方を体験→原則を学ぶ→自分で配色を設計）、アクセシブルなデザインは特別な人だけでなく皆に優しいこと、次回は「自分で設定したペルソナ」のために設計すること。前向きでやさしい締め。
